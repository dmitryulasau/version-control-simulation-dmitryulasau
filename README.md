# Version Control Simulation (Lab 1.1)

## Project Overview

This project was created for my Version Control assessment. I practiced using Git and GitHub, working with branches, merging changes, and resolving merge conflicts.

## Features

- Basic HTML page structure
- Header section with navigation
- Footer section with copyright information

## Git Workflow

The following branches were used during this project:

- `main` - Main project branch.
- `feature/header` - Used to create the header section.
- `feature/footer` - Used to create the footer section.

## Merge Conflict

I created a merge conflict by changing the same part of `index.html` in two different branches. I resolved it by reviewing the changes, accepting both, and committing the final version.

## Collaboration
Reviewed a peer’s pull request on GitHub, checked the code changes, and verified that everything looked correct before approving the changes.
